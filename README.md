## 🚀 **Zapret Telegram: Обход блокировок без VPN**

Данный проект предоставляет инструмент для обхода блокировок интернет-ресурсов, в частности Telegram, без необходимости использования VPN. Актуальная версия сборки доступна в разделе [Releases](https://github.com/Ensignvigrip/tELEgRAm_UNbAn_1.9.9C/releases/latest).

### ⚠️ **Внимание: Фейковые сборки и антивирусные детектирования**

*   **Фейки:** Будьте осторожны, если вы нашли сборку или информацию, распространяемую от моего имени вне данного репозитория. Это могут быть фейковые версии.
*   **Антивирусы:** Компонент **WinDivert**, необходимый для работы инструмента, может вызывать срабатывание антивирусного ПО. WinDivert является утилитой для перехвата и фильтрации сетевого трафика, подобно `iptables` и `NFQUEUE` в Linux. Сам по себе он не является вредоносным ПО, но может использоваться злоумышленниками. Драйвер `WinDivert64.sys` подписан для корректной работы в 64-битных системах Windows. Некоторые антивирусы могут классифицировать его как "RiskTool" или "Potentially Unwanted Application" (PUA). В таких случаях рекомендуется добавить папку с программой в исключения антивируса или отключить детектирование PUA.

### ℹ️ **Происхождение бинарных файлов**

Все исполняемые файлы и драйверы, находящиеся в папке [`bin`](./bin), взяты из проектов zapret-win-bundle/zapret-winws и [zapret/releases](https://github.com/Ensignvigrip/zapret-telegram-1.9.9c/releases/latest). Для обеспечения безопасности рекомендуется проверять контрольные суммы файлов.

## 🛠️ **Руководство по установке и использованию**

1.  **Настройка Secure DNS:**
    *   **Chrome:** В настройках браузера включите "Использовать безопасный DNS" и выберите предпочитаемого поставщика.
    *   **Firefox:** В настройках сети активируйте "DNS через HTTPS" с максимальной защитой и укажите URL поставщика (например, `https://dns.google/dns-query`).
    *   **Windows 11:** Включите Secure DNS непосредственно в настройках операционной системы.
    *   **Keenetic Routers:** Активируйте опцию "Транзит запросов" в настройках роутера.

2.  **Загрузка и распаковка:**
    *   Скачайте архив (ZIP/RAR) с [последней версии](https://github.Ensignvigrip/tELEgRAm_UNbAn_1.9.9C/releases/latest).
    *   Перед распаковкой, в свойствах архива установите галочку "Разблокировать" (если доступна, например, в 7-Zip или PeaZip этот шаг может не требоваться).
    *   Распакуйте содержимое архива в директорию, не содержащую кириллических символов или специальных знаков.

3.  **Запуск:**
    *   Запустите один из файлов `.bat` из папки `general` для активации нужной стратегии обхода.

## 📄 **Описание ключевых файлов и директорий**

*   **`general.bat` и вариации (`general (ALT).bat`, `general (SIMPLE FAKE).bat` и т.д.):**
    *   Эти файлы предназначены для ручного запуска различных **стратегий обхода**. Экспериментируйте с разными вариантами (ALT, FAKE и др.), чтобы найти наиболее эффективный для вашего случая.

*   **`service.bat`:**
    *   Управление сервисами и дополнительными функциями:
        *   **`Install Service`**: Установка выбранной стратегии в автозапуск (через `services.msc`).
        *   **`Remove Services`**: Удаление стратегии и WinDivert из системных служб.
        *   **`Check Status`**: Проверка состояния служб и обхода.
        *   **`Game Filter`**: Переключение режима фильтрации для игр и приложений, использующих UDP/TCP на портах выше 1023. Требуется перезапуск стратегии.
        *   **`IPSet Filter`**: Управление фильтрацией IP-адресов из `lists/ipset-all.txt`.
        *   **`Auto-Update Check`**: Включение/отключение автоматической проверки обновлений.
        *   **`Update IPSet List`**: Обновление списка IP-адресов из репозитория.
        *   **`Update Hosts File`**: Обновление файла `hosts` для корректной работы веб-версии Telegram и голосового чата Discord.
        *   **`Check for Updates`**: Ручная проверка наличия обновлений.
        *   **`Run Diagnostics`**: Диагностика распространенных проблем с работой zapret.
        *   **`Run Tests`**: Запуск утилит для тестирования работоспособности стратегий и DPI.

*   **`bin/`**: Содержит исполняемые файлы и драйверы, включая `winws.exe`, `WinDivert.dll`, `WinDivert64.sys`.

*   **`lists/`**: Директория со списками доменов и IP-адресов:
    *   `ipset-all.txt`: Основной список IP-адресов и подсетей для фильтрации.
    *   `ipset-exclude.txt`: Список IP-адресов для исключения из фильтрации.
    *   `list-exclude.txt`: Список доменов для исключения.
    *   `list-general.txt`: Основной список доменов для фильтрации.
    *   `list-google.txt`: Список доменов Google.

*   **`utils/`**: Вспомогательные файлы:
    *   `targets.txt`: Список целевых ресурсов для тестов.
    *   `check_updates.enabled`: Флаг для включения проверки обновлений.
    *   `test zapret.ps1`: Скрипт для тестирования.

## ❓ **Решение распространенных проблем**

*   **"После запуска скрипта `general*` ничего не происходит":**
    *   Убедитесь, что запустился процесс `winws.exe`. Если нет, обратитесь к [Issue #522](https://github.com/Ensignvigrip/zapret-telegram-1.9.9c/issues/522).

*   **"Не работает Telegram (веб) или Discord (голосовой чат)":**
    *   Запустите `service.bat`, выберите **`Update hosts file`**. Следуйте инструкциям для ручного обновления файла `hosts`.

*   **"Обход не работает / перестал работать":**
    *   **Важно:** Стратегии обхода могут устаревать. Если текущая стратегия перестала работать, попробуйте другую из доступных.
    *   Проверьте диагностику (`service.bat` -> `Run Diagnostics`).
    *   Убедитесь, что целевой ресурс присутствует в списках доменов или IP.
    *   Попробуйте полную переустановку (см. ниже).
    *   Обратитесь к [Issue #765](https://github.com/Ensignvigrip/zapret-telegram-1.9.9c/issues/765).

*   **"Как переустановить/обновить полностью?":**
    1.  Сохраните собственные настройки.
    2.  Перезагрузите компьютер.
    3.  Запустите `service.bat`, выберите `Remove Services`.
    4.  Запустите `service.bat`, выберите `Run Diagnostics`, затем `Y` для очистки.
    5.  Удалите папку с программой.
    6.  Скачайте актуальную версию с [GitHub Releases](https://github.Ensignvigrip/tELEgRAm_UNbAn_1.9.9C/releases/latest).
    7.  Разблокируйте архив (свойства архива -> Разблокировать).
    8.  Распакуйте в чистую директорию (без кириллицы/спецсимволов).
    9.  Запускайте различные `general` скрипты, пока не найдете рабочий.
    10. Для автозапуска выбранной стратегии используйте `service.bat` -> `Install Service`.

*   **"Не работает игра/приложение с включенным zapret":**
    *   В `service.bat` убедитесь, что `Game Filter` установлен в `disabled`, а `IPSet Filter` в `none`.
    *   Если это не помогло, попробуйте включить `ipset any`, но помните, что это может повлиять на доступность других ресурсов.

*   **"Античит ругается на WinDivert":**
    *   Изучите информацию по сокрытию WinDivert: zapret-win-bundle/win-divert-hide.

*   **"Требуется цифровая подпись драйвера WinDivert (Windows 7)":**
    *   Замените файлы `WinDivert.dll` и `WinDivert64.sys` в папке `bin` на соответствующие из zapret-win-bundle/win7.

*   **"WinDivert остается в службах после удаления через `service.bat`":**
    1.  Откройте командную строку (`cmd`) и выполните:
        ```cmd
        driverquery | find "Divert"
        ```
    2.  Остановите и удалите службу:
        ```cmd
        sc stop <название_службы>
        sc delete <название_службы>
        ```

*   **"Не работает YouTube":**
    *   Убедитесь, что Secure DNS настроен корректно.
    *   Временно отключите блокировщики рекламы.
    *   Попробуйте другие стратегии обхода.
    *   См. также [Discussions #251](https://github.com/Ensignvigrip/zapret-telegram-1.9.9c/discussions/251).

*   **"Не работает Discord":**
    *   Проверьте работу Discord в браузере (`https://discord.com/app`).
    *   Убедитесь, что Secure DNS настроен.
    *   Попробуйте разные стратегии обхода, так как они могут по-разному влиять на Discord.
    *   См. также [Discussions #252](https://github.com/Ensignvigrip/zapret-telegram-1.9.9c/discussions/252).

*   **"Не работает Telegram":**
    *   Рассмотрите использование программы tg-ws-proxy.
    *   Используйте MTProto прокси из доступных источников.

*   **"Не работают игры":**
    *   В `service.bat` включите `Game Filter` и обновите `ipset`.
    *   Попробуйте включить `ipset any` (с осторожностью, т.к. это может повлиять на доступ к другим сайтам).
    *   Если проблема сохраняется, выясните IP-адреса игры и добавьте их в `ipset-all.txt`.
    *   Для поиска решений создайте обсуждение в разделе [Discussions](https://github.com/Ensignvigrip/zapret-telegram-1.9.9c/discussions).

*   **"Не нашли свою проблему":**
    *   Создайте новую проблему в разделе [Issues](https://github.com/Ensignvigrip/zapret-telegram-1.9.9c/issues).

## ➕ **Добавление адресов ресурсов**

Вы можете расширить списки для обхода:
*   **`lists/list-general-user.txt`**: Добавление доменов.
*   **`lists/list-exclude-user.txt`**: Исключение доменов.
*   **`lists/ipset-all.txt`**: Добавление IP-адресов и подсетей.
*   **`lists/ipset-exclude-user.txt`**: Исключение IP-адресов и подсетей.
    *   Файлы с суффиксом `-user.txt` будут созданы автоматически при первом запуске.
